!!!СДЕЛАНО В УЧЕБНЫХ ЦЕЛЯХ!!! На сайте есть четыре серьёзные уязвимости. Эти уязвимости находятся в файлах auth.py и views.py - там же я прокомментировал эти уязвимости.

В репозитории две папки: RESHETO и RESHETO_VULNERABLE. RESHETO содержит уже пропатченную безопасную версию (все изменения можно посмотреть в коммитах Update auth.py и Update views.py). RESHETO_VULNERABLE - небезопасная версия. С её помощью можно проверить работоспособность уязвимостей.

Автоматически проверить уязвимости можно с помощью exploit.py (как именно — описано ниже).

1.Открыть cmd
2.Ввести в терминал: cd путь_до_папки_RESHETO (пример: cd C:\Users\user\Desktop\projects\RESHETO)
3.Ввести в терминал: python RESHETO.py (запускаем сервер)
4.Выведется куча разной инфы среди которой вам нужно найти: Running on "ваш_адрес"
5.Копируем этот адрес, открываем файл exploit.py в каком-либо редакторе и заменяем значение переменной BASE ( она должна быть на строке 3 ) вашим адресом
6.Ctr+s - сохраняем изменения в exploit.py
7.Открываем вторую cmd
8.Опять вводим в терминал: cd путь_до_папки_RESHETO (пример: cd C:\Users\user\Desktop\projects\RESHETO)
9.Вводим в терминал: python exploit.py (запускаем эксплоит)
10.Смотрим, что смогли 'наворовать"
